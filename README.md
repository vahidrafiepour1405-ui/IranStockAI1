# IranStockAI — شکارچی فرصت بورس ایران

این مخزن مستقل برای اپ تحلیل بازار سهام ایران است و به پروژه‌های WAL و WhaleHunterAI وابسته نیست.

## اجرا در Render
- Runtime: Docker
- Dockerfile: ./Dockerfile
- Health check: /health
- سرویس پیشنهادی: iran-stock-ai

## وضعیت داده‌ها
این نسخه اولیه است. پیش از استفاده معاملاتی باید دسترسی به منبع داده بازار و ساختار پاسخ‌ها در محیط واقعی آزمایش شود. هر داده بنیادی، ارزش ذاتی یا جریان خریدوفروش حقوقی که منبع معتبر و قابل‌راستی‌آزمایی نداشته باشد، نباید واقعی فرض شود؛ در نبود داده باید وضعیت ناکافی بودن داده نمایش داده شود.

## اجرای محلی
```bash
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000
```

مسیرهای سلامت و API در فایل main.py تعریف شده‌اند. کلیدهای API را فقط در Environment Variables سرویس میزبانی قرار دهید و هرگز در مخزن ثبت نکنید.
